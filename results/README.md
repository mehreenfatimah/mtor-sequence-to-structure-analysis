# Results

This folder contains selected figures extracted from the original MTOR semester project report so the GitHub repository includes visible analytical evidence.

- `01_blast_results.png` — NCBI/BLAST sequence-analysis evidence
- `02_vep_variant_analysis.png` — Ensembl VEP variant-analysis output
- `03_phylogenetic_tree.png` — multi-species MTOR phylogenetic tree
- `04_rna_structure.png` — RNAfold secondary-structure analysis
- `05_protein_structure.png` — protein-structure interpretation
- `06_pathway_analysis.png` — KEGG/Reactome pathway analysis

These figures document the original analysis. Public database annotations can change over time, so current API lookups may not exactly match historical screenshots.

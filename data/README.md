# Data

No large or proprietary biological dataset is committed to this repository. The scripts retrieve public MTOR records when run with internet access.

The original coursework identified human **MTOR (Gene ID 2475)** as the subject of analysis and used public resources including NCBI, Ensembl/VEP, MEGA, RNAfold, SWISS-MODEL, AlphaFold, KEGG and Reactome.
